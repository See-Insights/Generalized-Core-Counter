## Plain goal

Move the decision of how long to sleep and why out of `handleSleepingState()` into one named function in `State_Sleep.cpp`. That covers the openness and night commitment, the close-due guard, the night duration and clamp, the reporting-boundary alignment, the COUNTING LED defer and the OCCUPANCY debounce. The nightly heap guard moves into a second small function. **No behavior change:** the same durations, reasons, transitions, sensor and LED calls, `logTimeDiag` and reset decision.

## Design (option D; do not widen)

1. **A plan function.** It is one file-local function in the anonymous namespace. It fills a small plan struct with the three outputs and returns "handled" when it has already transitioned (close due, LED defer), so the caller returns exactly as today.
2. **A heap-guard function.** It is one file-local function that takes `overnightFallbackSleep` and returns "handled" on the reset path.
3. **Call order is unchanged:** plan, then `hibernateAttempt`, then the heap guard.
4. **Nothing else changes:** no new file or header, and no change to the S-1, S-2 or S-3 functions.
