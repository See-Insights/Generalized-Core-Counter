**Finding (INF, from the table):** "on change" must key on the rare, decision-relevant fields: `isOpen`, `openness` and `trusted`. `valid` can be added at no cost. It must not key on `epoch`, `utc`, `local` or `syncAgeMs`, because those change continuously. That would be the same flood at a lower rate (a per-second line is still about 86,400 lines/day). It also must not key on a per-minute epoch bucket, for the same reason (1,440 lines/day, all identical in meaning).

Not keying on `tz`, `open`, `close` or `lastSyncEpoch` is acceptable. A config change that matters flips `isOpen` or `openness`. A completed sync that matters flips `trusted`.

## 3. Smallest change
- **Where:** `State_Idle.cpp:37-38` (entry hook) and `:125` (the call). Nothing else.
- **Entry hook (OBS):** Idle has no `enteredState` variable (only `State_Sleep.cpp:334` does). It does have the same test inline: `if (state != oldState)` at `:37`, and `publishStateTransition()` sets `oldState = state` (`Generalized-Core-Counter.cpp:2485`). So transition detection exists, but `oldState` is overwritten before `:119` is reached.
- **Sketch in words:**
  1. At `:37`, store `state != oldState` in a local const before `publishStateTransition()` runs, and test that local in the `if` (+1 net).
  2. In the CONNECTED branch, compute `isWithinOpenHours()` once. Pack `isOpen`, `parkOpenness`, `isClockTrusted()` and `Time.isValid()` into one small integer key (+2).
  3. Keep one function-local `static` last-key, initialised to an impossible value (+1). Call `logTimeDiag()` only if the entry flag is set or the key differs, then store the key (+2 net, since it replaces the single unconditional call).
  4. Keep the passed `isOpen` argument sourced from `isWithinOpenHours()`. Keep `parkOpenness` as is.
- **Net estimate:** about +6 to +8 `src/` lines, including one short comment line. That is within the +10 budget. It adds one file-local static (allowed) and no timer, no persisted field and no new flag.
- **Transition coverage (INF):** the entry flag logs once on Sleep→Idle (`sleep-abort-open-hours`) and on any entry into Idle. The `valid`, `isOpen`, `openness` and `trusted` terms cover the in-state changes (open/close boundary, trust flip).
- **Caveat (INF):** if Idle returns early on its entry pass (`:73` or `:89`), the entry flag is spent before `:125`. The log is then skipped until a key change. The window is small and not worth extra state. If the architect wants it closed, one more `static` flag would be needed.
- **Constraints (OBS):**
  - No gate on `Time.isValid()` or `isWithinOpenHours()`. They only feed the key.
  - `isOpen=` and `openness=` stay separate.
  - The ceiling at `:295-298` is untouched.
