Detailed Description

Platform-specific pin mappings and pin-helper implementations.

Author
Chip McClelland @email chip@.nosp@m.seei.nosp@m.nsigh.nosp@m.ts.c.nosp@m.om

This file translates logical carrier-board signals into the correct pin names for each supported Particle platform so the rest of the firmware can stay platform-agnostic. It also owns the small LED helper routines used throughout the state machine.
