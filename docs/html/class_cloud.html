bool Cloud::areLedgersSynced ( ) const

Check whether the input ledgers are ready for the current sleep gate.

Returns true immediately once both cloud-input ledgers have synced. If neither ledger has synced after the connection window expires, the helper treats them as intentionally empty and also returns true. Partial sync after the timeout is treated as a real failure and returns false.

◆ calculateBatteryTier()

BatteryTier Cloud::calculateBatteryTier ( float currentSoC)
static

Calculate battery tier from current state of charge.

Implements 4-tier system with hysteresis to prevent tier thrashing:

  • TIER_HEALTHY (0): >70% SoC (recover at >75%)
  • TIER_CONSERVING (1): 50-70% SoC (recover at >55%)
  • TIER_CRITICAL (2): 30-50% SoC (recover at >35%)
  • TIER_SURVIVAL (3): <30% SoC
Parameters
currentSoCCurrent state of charge percentage (0-100)
Returns
BatteryTier enum value (0-3)

◆ getConnectionBackoffMultiplier()

float Cloud::getConnectionBackoffMultiplier ( uint16_t lastDurationSec)
static

Evaluate connection history and return backoff multiplier.

Analyzes lastConnectionDuration to determine location quality:

  • Fast (<60s): 1.0x (no additional backoff)
  • Normal (60-180s): 1.0x (no additional backoff)
  • Slow (180-300s): 1.5x (additional backoff)
  • Problem (>300s or failed): 2.0x (strong backoff)
Parameters
lastDurationSecLast connection duration in seconds (0 = failed)
Returns
Backoff multiplier (1.0, 1.5, or 2.0)

◆ getIntervalMultiplier()

uint16_t Cloud::getIntervalMultiplier ( BatteryTier tier)
static

Calculate connection interval multiplier based on battery tier.

Returns multiplier to apply to base reportingInterval:

  • TIER_HEALTHY: 1x (no change)
  • TIER_CONSERVING: 2x (half connections per day)
  • TIER_CRITICAL: 4x (quarter connections per day)
  • TIER_SURVIVAL: 12x (e.g., 1hr base → 12hr, 30min base → 6hr)
Parameters
tierCurrent battery tier
Returns
Interval multiplier (1, 2, 4, or 12)
